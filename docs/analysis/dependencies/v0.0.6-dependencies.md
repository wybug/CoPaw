# CoPaw v0.0.6 依赖分析文档

> **版本**: v0.0.6.post1
> **生成日期**: 2026-03-11
> **Python 要求**: >=3.10,<3.14

## 概述

CoPaw v0.0.6 是一个个人 AI 助手，支持多个聊天平台（DingTalk、Feishu、QQ、Discord、iMessage、Telegram、Matrix、Mattermost、MQTT）的本地运行环境。本文档记录该版本的完整依赖情况。

---

## 版本兼容性说明

### Python 版本
- **最低要求**: Python 3.10
- **最高支持**: Python 3.13 (不含 3.14)
- **推荐版本**: Python 3.11 或 3.12

### 系统要求
- **跨平台**: Linux, macOS, Windows
- **特殊依赖**:
  - `mlx-lm` 仅支持 macOS (Apple Silicon)
  - `iMessage` 通道仅支持 macOS

### 浏览器要求 (Playwright)
- Chrome/Chromium
- Firefox
- Safari
- Edge

---

## 安全注意事项

1. **API 密钥管理**: 所有第三方 API 密钥存储在 `~/.copaw/working.secret/`
2. **本地优先**: 所有数据和任务在本地运行
3. **无第三方托管**: 不依赖外部云服务
